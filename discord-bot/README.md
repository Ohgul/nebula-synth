# NEBULA Manager
Discord bot for NEBULA SYNTH. Railway root directory: `/discord-bot`.

Set `DISCORD_TOKEN` privately in Railway Variables and `DISCORD_GUILD_ID=1558948382746091653`. Do not commit `.env` files or tokens.

Required bot permissions: Manage Channels, Manage Roles, View Channels, Send Messages, Read Message History, Create Private Threads, Send Messages in Threads, Manage Threads. Enable Server Members Intent in the Discord developer portal. Ensure the bot role is above Beta Tester in Discord.

Commands: `/configurar`, `/publicar_panel`, `/dar_beta`, `/quitar_beta`, `/publicar_bienvenida`.

This bot manages Discord roles and tickets; **it does not implement 7-day VST license expiry**.
