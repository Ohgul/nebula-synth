# Nebula: versión 3

## Hecho
- [x] Interfaz neuronal: Cerebro con neuronas, axones y pulsos; fondo de red viva; locura que transforma toda la interfaz.
- [x] Resíntesis nueva: armónicos en el tiempo, parciales inarmónicos que siguen su frecuencia, ruido en 24 bandas, curva de tono, ancho estéreo.
- [x] Todo sample se afina a C. A/B con el original al mismo volumen.
- [x] Panel del sample simplificado: RECREAR, % de parecido y receta.
- [x] Perillas estilo Moog con LEDs, más chicas; curvas revisadas (FM, resonancia, drive, corte logarítmico) y menos recorrido de mouse.
- [x] Botones de encendido por sección.
- [x] Efectos: EQ, compresor, chorus, delay, reverb FDN, ancho estéreo.
- [x] Macros: Brillo, Cuerpo, Movimiento, Espacio, Locura.
- [x] Cerebro: mezclar, cruzar, memoria de generaciones.
- [x] Exportar arrastrando: MIDI de frases, audio y onda.
- [x] Explorador de presets (34) con categorías, búsqueda y favoritos.
- [x] Deshacer / rehacer.
- [x] Oversampling 2x / 4x, deriva analógica, MPE.
